# TODO-лист (Планировщик задач)

## Описание проекта
Этот веб-сервер на Go представляет собой планировщик задач (аналог TODO-листа). 
Он позволяет создавать, редактировать, удалять задачи, а также отмечать их выполненными. 
Приложение поддерживает правила повторения задач (ежедневно, через N дней, ежегодно), 
хранит данные в базе данных SQLite и имеет готовый фронтенд для работы в браузере.

## Выполненные задания со звёздочкой
- Реализована поддержка переменных окружения `TODO_PORT` и `TODO_DBFILE` (так как они необходимы для работы Docker-контейнера).
- Остальные задания повышенной трудности (аутентификация, поиск, расширенные правила повторения `w` и `m`) не выполнялись, так как основной упор был сделан на реализацию обязательного функционала согласно ТЗ.

## Инструкция по запуску кода локально
- Убедитесь, что установлен Go (версия 1.24 или выше).

- Установите зависимости: go mod tidy

- Запустите сервер: go run main.go

- Дополнительные флаги: вы можете переопределить порт или файл БД с помощью переменных окружения. Пример: TODO_PORT=8080 TODO_DBFILE=mybase.db go run main.go

- Откройте в браузере: http://localhost:7540
